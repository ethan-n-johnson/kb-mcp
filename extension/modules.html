Capture Canvas modules

To read the course and open its tools, Chrome has to allow KB Capture on https sites (the same access as "Capture embedded frames" in settings).

Tick modules or single items. External tools (such as the course readings) open one at a time in a separate window, which is scrolled and captured, then reused for the next one. Opening a tool counts as viewing it in Canvas. Items that look like labs, quizzes or assessments start unticked, because opening them may start a lab or an attempt.

PDFs and Canvas files found in pages and tools are always stored. With this ticked, every other web link in them is sent to the server to fetch as well (at most 300 per run; pages that need a login fail and are listed).
